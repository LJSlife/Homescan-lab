HomeScan v1.3 — for homeowners and landlords

INSTALL THE UPDATE
Extract this ZIP. Upload all six app files to your existing GitHub repository,
replacing matching files: index.html, sw.js, detection.js, manifest.webmanifest,
icon-192.png and icon-512.png. Open your existing site and refresh.
The bottom of the page should show HomeScan · v1.3.
Existing saved rooms stay on the same device, browser and website address.

USING HOMESCAN
1. Give the room a name.
2. Open the camera, then tap Start scanning. Move slowly and pause on items.
3. Tap Finish scanning. Check the names and quantities in your list.
   Choose Oven or Microwave if the app asks. Use Edit, Looks right, or Remove
   to make the list accurate. Add any missed items yourself.
4. Tap Save this room. Use Start a new room when you are ready for another.

Saved rooms can be opened again. Download room lists gives you a readable
text copy of all saved rooms. It is a copy for keeping or sharing, not a file
that can be imported back into the app. Camera footage is not included.
Room lists stay on this device; keep a downloaded copy if they matter to you.

The camera can mistake one item for another or miss items. Always check the
names and quantities. Similar objects viewed separately may need to be added
manually.
The live scanner still needs an internet connection to get ready.
