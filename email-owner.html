App owner only

Activate Gmail once.

After this, people can connect their Gmail account with a normal Google sign-in. They won’t see these setup steps.

This page guides the app’s registration. It cannot create a Google registration automatically. Use your own Google account. No password, secret or sign-in code belongs on this page.

1

Create the app’s Google project

Open Google Cloud in another tab. Sign in, open the project selector at the top, then choose New project. Name it Life Buddy. If you already have a project for this app, select it.

Open Google Cloud

If Google asks you to accept terms, read and accept them yourself. No paid hosting or billing account is required by this browser-based build.

2

Enable email and contacts

In Google Cloud, open APIs & Services → Library. Search for Gmail API, open it and tap Enable. Repeat for People API (the address book).

3

Set up the Google consent screen

Open Google Auth Platform and Get started. Use Life Buddy as the app name and your own support/contact email.

Choose an External audience. Keep it in Testing while checking your own app. Add your Gmail address under Test users.

Permissions to add under Data access

Reading is requested when connecting. Contacts and sending are requested when used.

https://www.googleapis.com/auth/gmail.readonly https://www.googleapis.com/auth/gmail.send https://www.googleapis.com/auth/contacts.readonly https://www.googleapis.com/auth/contacts.other.readonly

Testing is not public-launch approval. Gmail read access requires Google's applicable review before a public release. The included privacy page describes this build; add accurate support and owner information requested by Google.

4

Register this website

In Google Auth Platform → Clients, create a client. Choose Web application.

Under Authorised JavaScript origins, add this address exactly. It is the website address without the /Homescan-lab/ part:

https://ljslife.github.io

Save the client. Copy its Client ID, which ends in .apps.googleusercontent.com. This ID is public. Do not copy the client secret.

5

Put the connection into the app

Upload the downloaded email-config.js into the same GitHub folder as the app’s index.html, replacing the old file. Wait for GitHub Pages to finish, then reopen the app.

Tap Open email → Connect Gmail, choose your account and allow reading. Check your inbox summaries and original links. Contacts and sending request their permissions as you use them.

Downloading the file checks its format only; it does not verify Google's registration, permissions or delivery. Test the real connection before inviting anyone else.

Need help with the next step?

Show Bob the Google Cloud screen you have reached. Never share a password, sign-in code or client secret. The public Client ID is enough for Bob to finish the app configuration.
